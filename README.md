# Firm - Legal Packages Landing Page

A Next.js application showcasing strategic legal packages for businesses at different stages.

## Features

- 4 Strategic Legal Packages:
  - **The Strategic Start-Up™** - For founders launching legally and strategically
  - **The Strategic Brand™** - For entrepreneurs protecting their brand with IP
  - **The Strategic Contract™** - For business owners tightening their agreements
  - **The Strategic Scale™** - For 6-7 figure businesses ready to expand

## Tech Stack

- **Next.js 16** - React framework for production
- **TypeScript** - Type safety and better developer experience
- **Tailwind CSS v4** - Utility-first CSS framework
- **React 19** - Latest React features

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) to view the homepage
4. Navigate to [http://localhost:3000/packages](http://localhost:3000/packages) to view the packages landing page

## Project Structure

```
/app
  /packages
    page.tsx      # Packages landing page
  layout.tsx      # Root layout
  page.tsx        # Homepage
  globals.css     # Global styles with Tailwind
```

## Build for Production

```bash
npm run build
npm start
```
